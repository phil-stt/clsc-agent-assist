# Long-form corpus (SYNTHETIC stand-ins)

Short stand-ins for documents an agency would hold: ISO endorsement forms, product sheets, statute excerpts. The form texts are **paraphrased summaries written for this demo**, not ISO's copyrighted wording; the form numbers are real public identifiers. Statute excerpts quote public text and carry their citation.

`knowledge/extract.py` reads this directory and proposes graph edges for human review. The demo graph itself is seeded from curated YAML in `knowledge/seed/`.
